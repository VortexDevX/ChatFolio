# GPT-PDF Chrome Extension (Manifest V3)

This unpacked Chrome extension allows you to select message bubbles directly inside any ChatGPT conversation on `chatgpt.com` or `chat.openai.com` and export them with 1 click.

## How to Install (Unpacked):
1. Open Google Chrome or Microsoft Edge and navigate to `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode** toggle in the top-right corner.
3. Click the **Load unpacked** button.
4. Select this directory: `v:\Projects\Tools-Libraries\GPT-PDF\extension`.

## Features:
- **Floating HUD Badge:** A discrete `⚡ PDF Export` badge appears in the bottom right of any ChatGPT conversation.
- **In-Page Bubble Selection:** Click on any user or assistant message bubble to highlight it with a neon emerald outline.
- **Selective Export:** Only the selected bubbles are copied or transferred into the Studio for vector PDF generation.
- **Studio Quick-Link:** Click the extension popup icon to jump right into the GPT-PDF Studio at `http://localhost:8000`.
